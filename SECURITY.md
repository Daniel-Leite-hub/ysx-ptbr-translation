# Segurança

## Relatar um problema

Este projeto não deve receber chaves de API, saves, bancos de dados pessoais, arquivos originais do jogo ou outros dados privados em Issues, Pull Requests ou anexos.

Para relatar uma vulnerabilidade no Studio, no instalador ou no processo de distribuição, abra uma comunicação privada pelo perfil do mantenedor no GitHub. Se não houver uma forma privada disponível, abra uma Issue sem incluir detalhes exploráveis, credenciais ou arquivos confidenciais e escreva apenas que é necessário contato privado.

## Boas práticas

- Nunca publique chaves DeepL, tokens, senhas ou arquivos `.env`.
- Baixe instaladores somente pela página oficial de Releases.
- Confira os hashes publicados antes de executar um arquivo baixado.
- Não desative a proteção do Windows para executar arquivos não verificados.
- Use uma cópia legítima e compatível do jogo.

## Escopo

O código do projeto é separado do conteúdo do jogo e dos arquivos de tradução distribuídos nas Releases. A licença do código não concede direitos sobre o jogo, seus recursos ou ferramentas de terceiros.
